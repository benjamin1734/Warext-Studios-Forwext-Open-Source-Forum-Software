# @forwext/react-ui

Official accessible React primitives and extension-slot support for Forwext.

This package is optional and is not required by the native PHP frontend. React is a peer dependency for modern frontend consumers.

## Design tokens

Components consume the same `--forwext-*` CSS custom properties generated by the native theme/design-token system. `FORWEXT_CORE_DESIGN_TOKENS`, `designTokenCssVariable()` and `designTokenReference()` provide a typed/validated bridge without duplicating theme values in React code.

Import `@forwext/react-ui/styles.css` once in the modern frontend.

## Accessibility

The primitives use native semantic controls, keyboard-visible focus, status/alert live regions, loading state semantics and visually-hidden text rather than div-only imitation controls.

## Permission-aware UI

`PermissionProvider`, `useCan()` and `<Can>` can hide or reveal controls using a server-provided permission snapshot.

This is presentation logic only. Backend/API permission checks remain authoritative and must never be replaced by React visibility checks.
