# 08.06 — Global Content Discovery UX

## Added

- A shared global-discovery registry that maps user-facing categories to canonical search-document types.
- Core category contracts for Forum, Support, FAQ, Portfolio, Marketplace and Members.
- Contributor support so later first-party modules can join the same discovery experience without creating a parallel search UI.
- Search tabs and grouped result sections for simple type-based discovery.
- Progressive disclosure for advanced filters through a native details panel.

## Security and permission behavior

- Discovery tabs only narrow document types; they never create or widen access scopes.
- The existing `PermissionAwareSearchService` remains the backend authority for `search.use` and server-derived visibility scopes.
- Unknown document types, duplicate filters and cross-category type filters fail closed.
- Saved searches cannot be mixed with non-`all` category tabs or explicit type filters.
- Search result output remains HTML escaped.

## Future-module integration

Support, FAQ, Portfolio and Marketplace document types are defined as stable integration contracts, but 08.06 does not fabricate records or routes for modules that are not implemented yet. Those later modules must publish real permission-scoped `SearchDocument` records before results can appear.

## Runtime and data

- No database migration.
- No database reset or destructive update behavior.
- No new cPanel runtime dependency or background daemon.
