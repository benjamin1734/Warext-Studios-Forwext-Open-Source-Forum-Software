# 08.04 — SEO and structured data

- Added canonical/meta/OpenGraph/Twitter/JSON-LD rendering with absolute URLs derived only from configured canonical origin/base path.
- Added fail-closed response decoration: unrecognized/private HTML defaults to `noindex,nofollow`, and non-indexable non-HTML responses receive `X-Robots-Tag`.
- Added public-profile SEO verification that only accepts active accounts with effective `public` profile visibility and never selects private email/about/social/media data.
- Added canonical public profile selection: current custom `/u/{slug}` when present, otherwise `/members/{username}`.
- Added `robots.txt` with private/account/search/editor/attachment/API exclusions and canonical sitemap declaration.
- Added source-registry based `sitemap.xml`, RSS and Atom endpoints.
- Sitemap is bounded to 50,000 URLs; RSS/Atom are bounded to 100 entries by service contract.
- Current feed source is latest public profile changes; future forum/FAQ/portfolio/marketplace public routes extend the same discovery source interface.
- No migration is required; existing user/profile/custom-URL state is reused.
