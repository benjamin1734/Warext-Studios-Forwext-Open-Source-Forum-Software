# 08.05 — Navigation, member directory and stats

- Added shared ordered navigation registry with first-party module contribution ownership.
- Added responsive registry-backed navigation and escaped breadcrumb rendering to the native PHP layout.
- Reused existing `ForumNodeHierarchy::breadcrumb()` through a permission-rechecking forum breadcrumb builder.
- Upgraded the public member directory with bounded search, sorting, count and pagination while preserving active/public-only visibility.
- Added five-minute user presence with one-minute write throttling and `hidden` / `members` / `public` visibility; default is member-only rather than anonymous-public.
- Added online-user listing that cannot bypass account/profile privacy.
- Added same-origin guarded presence heartbeat and user-controlled visibility endpoint.
- Added permission-scoped forum statistics that count only discoverable `forum.view` scopes and exclude hidden/deleted/moderated content.
- Added migration `20260917233000_user_presence` and clean-install registry integration.
