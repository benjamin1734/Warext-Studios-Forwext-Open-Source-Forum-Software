# 11.04 — My Bug Reports

Implemented reporter-facing bug history, detail, follow-up and notification tracking.

- Added authenticated `/bugs` **Hata Bildirimlerim** list with status, date, category, severity and detail links.
- Added permission-aware `/bugs/{reportId}` detail showing original intake, attachments, workflow history and public replies.
- Added `bug.report.reply_own` for reporter follow-up information and `bug.report.reply_all` for staff public responses.
- Added append-only bug report messages with nullable historical authors.
- Added durable notifications for staff replies, reporter follow-up to the current assignee and status changes.
- Added permission-aware private bug attachment downloads with byte-size/SHA-256 integrity verification.
- Added additive migration `20260918024000_bug_report_conversation`.
- Added XSS/IDOR/reply/status-notification regression coverage.
- Staff dashboard, duplicate handling, filters, search, analytics, export and centralized bug audit remain 11.05.
