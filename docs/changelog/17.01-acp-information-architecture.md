# 17.01 — ACP Information Architecture

- Added backend-authorized native PHP ACP dashboard at `/admin`.
- Reused the existing `acp.access` permission instead of introducing an administrator bypass.
- Added permission-aware global ACP search over bounded static navigation metadata.
- Added real action-needed counters for support, bugs, moderation reports and moderation tasks.
- Added per-user favorites and recent navigation with bounded/deduplicated preference storage.
- Added POST + CSRF navigation/favorite actions so recent state is not mutated by cross-site GET requests.
- Added a validated static first-party navigation registry to prevent arbitrary/open redirect targets.
- Added reusable ACP breadcrumb rendering and simple management sectioning.
- Added additive/idempotent MySQL/MariaDB navigation preference migration.
- Added preference, permission filtering, migration and native web-surface regression coverage.
- No new runtime dependency is required; native PHP and the minimum cPanel deployment remain supported.
