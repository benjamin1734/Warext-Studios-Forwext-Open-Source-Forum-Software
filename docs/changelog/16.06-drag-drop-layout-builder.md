# 16.06 — Drag-drop Page / Layout Builder

- Added a versioned layout document model with opaque widget placement ids.
- Added validated route/audience/device conditions and desktop/tablet/mobile preview semantics.
- Added move/reorder/duplicate-ready placement representation and deterministic ordering.
- Added immutable draft revisions with separate draft/published pointers.
- Added optimistic-concurrency safe publishing.
- Added versioned, layout-scoped and size-bounded JSON import/export.
- Enforced registered slot/widget validation before save and publish.
- Enforced appearance.manage for management and appearance.advanced for import/publish.
- Added central administration audit events for save/import/publish.
- Added MySQL/MariaDB migration for layout identities and revisions.
- UI drag/drop, undo/redo and device preview surface is part of the same roadmap step and is wired separately from the persistence commit.
