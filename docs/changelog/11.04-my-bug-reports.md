# 11.04 — Hata Bildirimlerim

Implemented the authenticated reporter-facing bug-report history and detail workflow.

## Added

- `/bugs/my` reporter-scoped list with status, date, category and severity.
- Permission-aware report detail with original intake, public history and private attachments.
- Reporter additional-information workflow for active reports.
- Public staff-response history events with backend staff permission checks.
- Durable bug status/staff-response notifications through the shared notification engine.
- Assigned-staff notification when the reporter adds new information.
- Integrity-checked private attachment downloads.
- Icon-only **Hata Bildirimlerim** shortcut next to the global bug-report icon.
- New submissions redirect directly to their detail page.
- Regression coverage for history visibility, terminal-state rules, notification hooks, IDOR boundaries, attachment integrity and escaped HTML.

## Security

- `bug.report.view_own` remains mandatory for reporter access.
- Other users cannot read a report or attachment by guessing ids.
- Staff response requires `bug.report.view_all` plus `bug.report.manage`.
- Reporter messages are bounded to 10,000 bytes and rendered with HTML escaping.
- Attachment downloads verify stored length and SHA-256.
