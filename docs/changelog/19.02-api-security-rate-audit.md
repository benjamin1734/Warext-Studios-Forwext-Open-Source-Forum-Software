# 19.02 — API security/rate/audit

Status: **completed**

Version: `0.0.7.58-dev`

## Delivered

- Personal access token, API key and OAuth-type API principal contexts.
- Digest-only credential persistence with expiry/revocation/last-use state.
- Protected-route scope authorization.
- Common Forwext account-permission intersection.
- Principal-isolated private notifications, support tickets and conversation summaries.
- API-specific rate limits over the shared store abstraction.
- Consistent JSON errors including router-level API 404/405.
- Authenticated API audit events with secret-safe snapshots.
- Additive API credential migration.

## Security invariants

- Raw credentials are never persisted.
- Invalid presented credentials never silently downgrade to anonymous access.
- Multiple simultaneous credential mechanisms are rejected.
- A token scope cannot bypass a denied account permission.
- Private rows are filtered by the authenticated principal's user id.
- Audit snapshots never contain raw credentials/Authorization headers.
- Standard cPanel runtime does not require Redis or a daemon.
