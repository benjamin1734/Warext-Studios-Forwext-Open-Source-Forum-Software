# 11.03 — Bug Report Form and Attachments

Implemented the first-party bug-report form and safe attachment flow.

- Added authenticated CSRF-protected `GET|POST /bugs/report`.
- Added reproduction steps, expected result and actual result intake fields.
- Added a global authenticated **Hata bildir** action through the shared native page shell.
- Added path-only source-page propagation without copying query strings or fragments.
- Kept automatic 11.02 diagnostic context authoritative and separate from user/browser supplied source-path metadata.
- Added screenshot/file upload using verified HTTP upload sources, signature/MIME inspection, image safety checks, metadata sanitation and private storage.
- Added maximum five attachments per report under the existing shared per-file quota.
- Added storage compensation if SQL submission fails after file persistence.
- Added additive migration `20260918023000_bug_report_form_intake`.
- Added regression coverage for atomic intake/diagnostic/attachment persistence, source-path privacy and form HTML escaping.
