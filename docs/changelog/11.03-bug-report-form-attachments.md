# 11.03 — Bug Report Form and Attachments

Implemented the page-accessible bug-report form and hardened attachment intake.

## Added

- Authenticated `/bugs/new` GET/POST form.
- Global icon-only bug-report entry on authenticated native PHP pages.
- Reproduction steps, expected result and actual result fields.
- Optional query-free source-page path hint.
- Inline multipart screenshot/file upload; no separate upload screen.
- Private attachment storage using the existing signature/MIME/image-metadata pipeline.
- Attachment byte-size/SHA-256 integrity metadata.
- Permission-aware private attachment download route.
- Additive migration `20260918023000_bug_report_intake`.
- Unit coverage for escaped form output, required fields, attachment limits, atomic persistence, source-path privacy and download integrity.

## Security and privacy

- Backend permissions remain authoritative.
- Source query strings and fragments are removed.
- Upload client MIME/filename are not trusted for media validation.
- Attachment downloads authorize the parent bug report first.
- Stored bytes are verified before download.
- Automatic diagnostics retain the 11.02 privacy rules and do not persist cookies, request bodies, raw User-Agent, IP or URL query strings.
