# 14.07 — Subscription / User Upgrades

- Added timed and lifetime first-party upgrade plans with durable user entitlement state.
- Added runtime role and flag-permission overlays so expiry/revocation affects authorization without rewriting normal user assignments.
- Added backend restrictions that prevent protected/staff/system roles and sensitive administration permission classes from being directly bound as upgrade entitlements.
- Added provider-backed purchase snapshots with amount/currency/duration immutability, idempotency and one-active-payment-attempt protection.
- Added verified, deduplicated server-to-server subscription payment webhooks with amount/currency/reference validation and SHA-256-only payload persistence.
- Added paid activation and renewal semantics that extend timed upgrades from the existing future end date and keep lifetime upgrades unbounded.
- Added read-repair/admin expiry normalization while keeping runtime authorization expiry-aware even before cleanup executes.
- Added native member `/account/upgrades`, purchase action, `/admin/subscriptions`, dedicated subscription CSRF and member navigation.
- Added migration `20260921220000_subscription_upgrade_system` for plans, bindings, subscriptions, purchases, webhook events and entitlement history.
- Added post-install navigation smoke coverage and regression tests for domain invariants, entitlement overlays, sensitive permission boundaries and webhook/CSRF wiring.
- Verified PHP 8.4/PHP 8.5 test/build run `35627236876` and MySQL 8.4/MariaDB 10.11 migration smoke run `35627236887`.
