# 17.03 — First-party Module Manager

- Added typed enabled/disabled/uninstalled lifecycle contracts for first-party modules.
- Added dependency/conflict graph validation with cycle detection and backend lifecycle enforcement.
- Added additive MySQL/MariaDB persistence for lifecycle state, scoped settings and durable storage purge objects.
- Added dedicated `module.manage` permission and administrator starter-profile grant.
- Added keep-data/delete-data uninstall policy with exact-key confirmation and Administration audit events.
- Added transactional database purge plus retryable storage purge queue.
- Added dependent-data purge protection before destructive parent uninstall.
- Added global/forum/group/thread/post typed settings with validated targets and reset-to-fallback behavior.
- Added native PHP `/admin/modules` ACP with lifecycle controls, graph visibility and scoped settings.
- Added route lifecycle enforcement and conditional ambient middleware gating for Easter Egg, Advertising and Analytics.
- Added ACP navigation integration, CSRF protection, noindex/no-store behavior and mobile-responsive UI.
- Added registry, runtime middleware, migration, security and native web-surface regression coverage.
- CI validation remains authoritative before 17.03 is marked completed.
