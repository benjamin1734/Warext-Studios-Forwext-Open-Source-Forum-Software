## Security and permission impact

- Redis, database and Meilisearch services are not published to host ports in the reference Compose topology.
- S3 and search credentials remain in the encrypted secret store and are not committed to deployment files.
- S3 signing never includes the secret key in URLs or errors; private access uses bounded presigned URLs.
- Realtime WebSocket mode only publishes backend envelopes to Redis. A client-facing gateway must authenticate and authorize each private channel subscription.
- The health route exposes detailed results only when the existing health.public_details setting explicitly permits them.
- No authorization or domain permission rules are bypassed by the deployment profile.
