# 15.03 — Content and Engagement Analytics

- Added forum/category/thread performance aggregation for selected 7/30/90-day windows.
- Added authoritative reaction/bookmark/watch/follow metrics and privacy-aware forum/thread view analytics.
- Extended the analytics event model with explicit policy-gated structural content references and registered `content.thread.view`.
- Added recursive category aggregation across descendant forums.
- Added reaction/view, bookmark/view and watch/view engagement proxy tables with explicit non-commerce semantics.
- Added privacy-aware search analytics with safe/redacted/short query classes and bounded result buckets.
- Added HMAC-keyed daily safe search-term aggregation while preventing e-mail, URL, IP, phone/long-number and malformed queries from being stored as visible terms.
- Added `/admin/analytics/content` with `analytics.view_site`, strict ranges and private no-store/noindex responses.
- Added migration `20260921232000_content_engagement_analytics` for structural event references, search-term aggregates and engagement query indexes.
- Added CI concurrency rules so superseded normal build/DB runs are cancelled without cancelling release commits, and removed unsafe automatic unpublished-version retry from later normal commits.
- Added regression coverage for structural-content policy, search privacy, engagement proxy models, route wiring and migration registration.
- Added architecture documentation at `docs/architecture/content-engagement-analytics.md`.
