# Forwext 1.0.3 — Native forum UI pass 1

This release reopens final production acceptance and begins closing the gap between the completed backend/service checklist and the native PHP user experience required by the binding v2.0 plan.

## Added

- A real native PHP forum index replaces the temporary installation-health home card.
- Public routes: `/forums`, `/forums/{slug}` and `/threads/{threadId}`.
- Category/forum hierarchy rendering with descriptions, thread/post counts and latest activity.
- Recent thread discovery and community quick links on the forum home surface.
- Forum thread lists with sticky, featured and locked states, reply counts, latest activity and pagination.
- Public thread reading with post cards, author information, safe BBCode rendering, timestamps, breadcrumbs and pagination.
- Responsive forum layouts for desktop, tablet and mobile using the existing design-token/component system.
- `Forumlar` is now a primary navigation entry.
- An idempotent starter category/forum (`Genel` → `Genel Sohbet`) is seeded only when a site has no forum nodes. Existing sites are not overwritten.

## Acceptance and regression coverage

- Post-install smoke now uses a real browser User-Agent.
- Fresh installation acceptance requires the native forum home marker and the usable `/forums/genel-sohbet` route.
- MySQL 8.4 and MariaDB 10.11 migration/post-install smoke cover the starter forum migration and public forum surface.
- Added public read-model tests for visibility filtering, counters and thread listing.
- Fixed a database portability bug where a window-function alias conflicted with SQL syntax on both supported database engines.

## Production acceptance status

The historical 20/20 main-step and 138/138 sub-step checklist remains useful as an implementation history, but it is no longer treated as proof of final product acceptance. Final acceptance remains open until required native public and ACP workflows are fully usable end-to-end.

Next remediation pass: thread creation/reply/editor workflows plus authentication/account entry surfaces.
