# 0.0.7.01-dev — immutable side-release policy

- Introduces separate side-update versions such as `0.0.7.01-dev`, `0.0.7.02-dev`, independent from main milestone tags such as `0.0.7-dev`.
- Makes published GitHub release tags and ZIP assets immutable; existing releases are never overwritten with `--clobber`.
- Publishes a new GitHub Release only when `VERSION` changes or an explicit manual publication targets a new version.
- Validates main and side-update version formats and rejects non-monotonic release versions.
- Differential update ZIPs now chain from the immediately preceding immutable published release.
- Marks `v0.0.7-dev` as the historical transition baseline and `v0.0.7.01-dev` as the first release under the immutable side-update policy.
