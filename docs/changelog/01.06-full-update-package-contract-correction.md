# 01.06 contract correction — Full/update package names and manifest

This correction restores the binding delivery contract without claiming completion of later 20.x release-engine roadmap work.

- New full packages use `forwext-v<version>-full.zip`.
- New update packages use `forwext-v<version>-update.zip`.
- Update ZIP generation now writes `update-manifest.json` with source/target versions, add/replace/delete lists, migration files, rebuild actions and SHA-256 payload checksums.
- Historical immutable releases that already used `install.zip` may be read only as the previous full source for the next differential update; they are not renamed or overwritten.
- Added an architecture regression test covering package names, mandatory manifest fields and legacy-predecessor-only compatibility.
