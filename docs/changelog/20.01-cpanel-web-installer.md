# 20.01 — cPanel-first web installer

Version: `0.0.7.63-dev`

## Delivered

- Browser-only cPanel installer with reusable PHP/runtime/file-system preflight.
- Site identity, canonical URL, locale and IANA timezone configuration.
- MySQL/MariaDB connectivity plus migration-backed clean installation.
- Active first administrator with password credential, primary group, protected administrator role and release-current administrator permission template.
- Disabled/SMTP mail configuration with database and SMTP secrets kept in the encrypted secret store.
- First-party module selection with dependency/conflict validation and persisted module states.
- Published initial theme revision and compiled theme cache.
- Post-install health checks before the permanent installed-version lock is written.
- cPanel Cron Jobs instructions for the bounded webhook worker; terminal access remains unnecessary for installation.
- Fail-closed rejection of unrelated pre-existing Forwext users and safe recovery of the installer’s own interrupted bootstrap state.
- Installer security headers, no-store responses, session CSRF protection and non-reflected password fields.
- MySQL 8.4 and MariaDB 10.11 acceptance coverage for the complete administrator/module/theme/health bootstrap path.
