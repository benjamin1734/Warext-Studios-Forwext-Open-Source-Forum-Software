# 10.05 — FAQ ↔ Support Bridge

Implemented the roadmap FAQ/support integration.

- Added bounded category/tag/question/answer FAQ candidate retrieval for support recommendations.
- Re-checks every recommendation through the existing FAQ visibility/permission service before rendering.
- Added FAQ suggestions during ticket creation and prefills the support subject from the recommendation query.
- Added related FAQ guidance to resolved/closed ticket detail pages.
- Added `support.faq_draft.suggest` as a granular staff permission.
- Added public-staff-message-only FAQ draft suggestions with same-ticket validation.
- Added FAQ-manager review at `/faq/manage/support-drafts`.
- Applying a support suggestion creates an inactive, staff-visible normal FAQ article draft rather than auto-publishing it.
- Added additive migration `20260918015000_faq_support_bridge` with source-message uniqueness and permission defaults.
- Updated FAQ article persistence to join an existing transaction so article + draft-state application is atomic.
- Added regression coverage for visibility-safe recommendations, internal-note rejection and draft application.
