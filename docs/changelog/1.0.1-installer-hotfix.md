# Forwext 1.0.1 — Installer rendering hotfix

This maintenance release fixes a production web-installer rendering failure discovered during a real cPanel/browser installation of Forwext 1.0.0.

## Fixed

- The **6. İlk modüller** installer stage now renders the registered first-party module `label` property instead of the non-existent `name` property.
- The previous template mismatch could terminate PHP rendering at the first module row under strict typing, leaving the module area blank and preventing **7. Tema başlangıcı** and **8. Kurulum ve doğrulama / Forwext’i Kur** from appearing.
- Added a regression test that protects the module display-property contract and verifies that the theme/final installation stages remain present after the module stage.

## Upgrade / installation impact

- No database migration is required.
- Existing successfully installed sites are unaffected.
- Anyone installing from scratch should use the 1.0.1 full package instead of the 1.0.0 full package.
- The 1.0.1 differential update contains the installer correction for existing 1.0.0 deployments, although this issue primarily affects fresh browser installation.
