# 11.02 — Automatic Bug Diagnostic Context

Implemented the privacy-safe automatic diagnostic context layer required by roadmap sub-step 11.02.

- Added query-free URL path and matched route capture.
- Added authenticated user id plus canonical forum/thread/post route-context ids.
- Added theme attribute support with native `default` fallback and route-derived module keys.
- Added browser family/version, OS family and device-class classification.
- Reused the existing secret-backed authentication fingerprint engine for HMAC User-Agent fingerprints; raw User-Agent is never persisted.
- Added request-id correlation without copying request logs into bug reports.
- Explicitly excludes raw query strings, request bodies, cookies, client IPs and raw User-Agent text.
- Added `BugReportSubmissionService` so report creation and diagnostic persistence share one database transaction.
- Added additive migration `20260918022000_bug_diagnostic_context` with privacy-safe diagnostic indexes.
- Added regression coverage for query-secret removal, route entity extraction, safe fallbacks, client classification/fingerprinting and atomic submission.
- Form/attachments remain 11.03; reporter UI 11.04; duplicate/dashboard/search/export/audit remain 11.05.
