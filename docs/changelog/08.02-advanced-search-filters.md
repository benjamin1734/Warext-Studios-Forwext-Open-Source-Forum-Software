# 08.02 — Advanced search and filters

- Added the native PHP `/search` surface and integrated it into normal navigation.
- Added bounded advanced filters for forum, user, date range, prefix, tag, state, thread type and content type.
- Added the saved-query extension point for later first-party/add-on search presets.
- Preserved backend `search.use` enforcement and server-derived permission scopes; filter values cannot expand the actor's authorized search scope.
- Added validation/pagination bounds, escaped rendering and responsive mobile/desktop search UX.
