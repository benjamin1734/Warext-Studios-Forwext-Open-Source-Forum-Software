# 07.06 — Notification Sound System

- Added per-user notification sound preferences with global mute, bounded `0–100` volume and a selectable default sound preset.
- Added per-category enable/disable and preset overrides with reset-to-inherited behavior.
- Added four local first-party Web Audio presets (`soft`, `chime`, `pulse`, `minimal`) without external media URLs or user-supplied audio.
- Reused the shared notification permission engine through `notification.alert.view` and `notification.preference.manage`.
- Added server-side effective playback planning for mute, zero volume, category disable, preset fallback and normalized volume.
- Added authenticated native PHP settings/category routes, dedicated CSRF scope and base-path-aware asset/API paths.
- Added autoplay-safe browser playback that only unlocks after real pointer/keyboard/touch interaction and never queues pre-unlock sounds for delayed surprise playback.
- Kept audio supplementary to the visual notification path and documented graceful behavior for unsupported/blocked Web Audio.
- Added migration `20260917002000_notification_sound`, clean-install registry coverage, service/migration/web-surface tests and architecture documentation.
