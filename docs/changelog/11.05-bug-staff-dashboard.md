# 11.05 — Staff Bug Dashboard and Duplicate Workflow

Completed the staff-facing bug management workspace.

## Added

- Permission-gated `/bugs/staff` dashboard.
- Staff title/summary search and status/severity/category/assignee filters.
- Assignment and unassignment controls on bug detail pages.
- Category, severity and lifecycle management controls.
- Advisory duplicate similarity suggestions.
- Explicit canonical duplicate linking with a dedicated persisted relation.
- Staff summary and category analytics.
- Filtered CSV export with spreadsheet formula-injection mitigation.
- Central `bug` audit scope for replies, workflow changes, duplicate links and exports.
- `bug.report.export` and `bug.audit.view` permissions.
- Additive idempotent migration `20260918025000_bug_staff_workflow`.
- Regression coverage for duplicate ranking/no-auto-mutation, explicit duplicate transactions, audit behavior, dashboard escaping and CSV safety.

## Security

- Dashboard access requires `bug.report.view_all`.
- Workflow and duplicate mutations require `bug.report.manage`.
- Assignment uses `bug.report.assign` and the existing staff-access validation.
- Export and audit visibility use dedicated backend permissions.
- Search parameters are bound and LIKE wildcard characters are escaped.
- Duplicate detection does not automatically change state.
- CSV formula prefixes are neutralized before export.
- Staff responses and user content are escaped when rendered.
