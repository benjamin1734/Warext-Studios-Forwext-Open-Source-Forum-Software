# 10.04 — FAQ System

Implemented the production FAQ/SSS system required by roadmap step 10.04.

- Added typed FAQ categories and articles with language, public/member/staff visibility, ordering and active state.
- Added article tags, unique language-local SEO slugs and optional SEO title/description.
- Effective visibility always uses the stricter category/article setting.
- Added authenticated one-vote-per-user helpful analytics with updateable votes and aggregate ratios.
- Added permission-gated versioned JSON import/export; analytics and user identity data are excluded.
- Added native `faq.article` search content source and permission-derived FAQ search scopes.
- Category visibility edits queue every affected existing article for re-indexing.
- Added public FAQ index, canonical article route, permission-aware id redirect and management surface.
- Added dedicated FAQ CSRF scope and escaped HTML output.
- Added FAQPage JSON-LD, canonical SEO metadata and public FAQ sitemap/feed discovery.
- Added public SSS main-navigation entry.
- Added additive migration `20260918014000_faq_system` and regression coverage for visibility, search scope, SEO and XSS behavior.
- Ticket-to-FAQ suggestion/draft workflows remain 10.05.
