# 20.02 — Full ZIP + update ZIP release system

Version: `0.0.7.64-dev`

## Delivered

- Immutable `forwext-v<version>-full.zip` clean-install package contract.
- Immediate-predecessor `forwext-v<version>-update.zip` differential package contract.
- Machine-readable `update-manifest.json` with source/target versions and add/replace/delete operations.
- SHA-256 checksum coverage for every changed payload file plus external checksum files for both ZIP artifacts.
- Protected mutable paths for generated configuration, key material, installed-version state, secrets, uploads, logs, backups and public runtime storage.
- Migration discovery from changed release payload files.
- Archive-level validation for path traversal, exact payload/manifest correspondence, disjoint operations and checksum integrity.
- Immutable GitHub Release enforcement; an already published tag or release cannot be overwritten.
- Compatibility read of historical legacy install ZIPs only when they are the immutable immediate predecessor.
