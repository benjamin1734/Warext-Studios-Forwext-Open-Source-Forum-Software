# 18.02 — Events/decorators/DI extension API

Forwext now has an owner-aware, deterministic extension composition primitive that reuses the production container and domain-event infrastructure.

- `ExtensionOwner` identifies core, module and canonical `Vendor/AddOn` contributors.
- `Container::bindExtension()` adds owned bindings without permitting production overrides.
- `Container::decorate()` supports deterministic priorities, conflict checks, cycle detection and type preservation.
- Existing named domain events remain compatible; `listenTyped()` adds class-based listeners and both paths support owner/priority metadata.
- `ExtensionGraphDiagnostics` exposes a read-only graph of binding/decorator/listener state without resolving services.
- Authorization remains independent and backend-enforced; extension registration never creates permissions.
- No database migration or new mandatory cPanel runtime dependency was introduced.
