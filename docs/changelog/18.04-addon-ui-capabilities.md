# 18.04 — Add-on UI capabilities

Status: **completed**

## Delivered

- Namespaced UI slots, widgets, public navigation and design-token contributions.
- Safe escaped add-on templates using the existing theme template compiler.
- Declarative thread/post editor toolbar extensions.
- Immutable same-origin CSS/JavaScript compilation with SHA-256 and SRI.
- Lifecycle-aware active UI registry.
- One native runtime composer covering all 18.04 capability types.
- Data-only React/Next.js extension manifest and TypeScript contract.
- PHP 8.4/8.5, MySQL 8.4 and MariaDB 10.11 regression coverage.

## Security boundaries

- UI registration does not grant permissions.
- Disabled/uninstalled/unknown add-ons remain inactive.
- Template source is not executable PHP.
- Compiled asset paths are hash-derived and symlink-protected.
- CSS cannot add remote/executable URLs through this contract.
- Assets remain same-origin, so the existing CSP does not need to be weakened.
- React consumers receive metadata rather than secrets or backend implementation objects.
