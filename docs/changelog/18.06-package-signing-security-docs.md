## Security invariants

- A checksum proves integrity only, not publisher identity.
- Any explicitly supplied signature must validate; it cannot silently downgrade to unsigned.
- Official status comes only from locally trusted keyring metadata.
- Capability disclosure is not a permission grant or sandbox.
- Unknown capability names fail manifest validation.
- Private signing keys are never bundled into Forwext packages.
- Dependency planning never downloads remote code.
- Existing backend permissions/lifecycle checks remain authoritative.
