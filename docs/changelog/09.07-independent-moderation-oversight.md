# 09.07 — Independent Moderation Oversight

Implemented the independent tamper-evident moderation oversight system.

- Added a separate append-only moderation oversight stream in addition to the operational 09.06 Core Audit Stream.
- Added canonical redacted payloads, payload hashes, previous hashes, monotonic sequence numbers and SHA-256 chain hashes.
- Serialized concurrent appends through a row-locked chain state and kept oversight append in the same moderation mutation transaction.
- Added full paged chain verification for sequence, payload, previous-link, chain-hash and final-state consistency.
- Added review cases and anomaly flags as separate annotations that never mutate chained entries.
- Added backend self-review protection: a reviewer cannot open/resolve cases or add/resolve flags for their own moderation event.
- Added `audit.review` built-in template defaults while keeping read access under `audit.view`.
- Added native `/moderation/oversight` UI with explicit verification and same-origin guarded review/flag mutations.
- Added additive migration `20260918006000_independent_moderation_oversight`.
- Intentionally did not backfill pre-09.07 events into the hash chain because retroactive hashes cannot establish historical tamper evidence.
- Added regression coverage for redaction before hashing, serialized append behavior, tamper detection and self-review denial.
