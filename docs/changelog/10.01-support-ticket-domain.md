# 10.01 — Internal Support/Ticket Domain

Implemented the production support-ticket core required by roadmap step 10.01.

- Added typed ticket priority and lifecycle status enums.
- Added category definitions with editable default priority and optional first-response/resolution SLA policy.
- Added immutable ticket entities with requester, optional assignee, lifecycle state, SLA snapshot and optimistic-lock version.
- Added permission-aware support application service for creation, own/all access, assignment, priority changes, lifecycle changes and first-response SLA recording.
- Added backend IDOR/BOLA protection: another user's ticket requires `support.ticket.view_all`.
- Added assignee validation against support staff access.
- Added database repository with prepared statements and version-checked optimistic updates.
- Added additive migration `20260918011000_support_ticket_domain` with category/ticket tables, foreign keys, queue/SLA indexes and built-in permission-template defaults.
- Seeded one editable `general` starter category without overwriting administrator edits on migration re-runs.
- Added unit coverage for SLA snapshotting, permission isolation, lifecycle reopen behavior, assignee authorization and SLA breach calculation.
- Dynamic forms/attachments remain 10.02; conversation/staff tools remain 10.03; dashboards/reporting/audit remain 10.06.
