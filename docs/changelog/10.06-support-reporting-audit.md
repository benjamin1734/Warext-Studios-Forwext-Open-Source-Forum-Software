# 10.06 — Support Panel, My Tickets, Reporting and Audit

Implemented the final support/FAQ roadmap sub-step.

- Added authenticated `/support/tickets` My Tickets page using server-derived requester scope only.
- Added permission-gated `/support/staff` dashboard with active queue, SLA breach counts, response/resolution averages and category metrics.
- Added `support.report.view` and `support.audit.view` permissions.
- Extended the central 09.06 audit stream with `support` scope rather than creating a parallel audit table.
- Added atomic support mutation audit for ticket create/reply/internal-note/assignment/status/escalation/merge/split and canned-response save.
- Deliberately excludes public/internal message bodies from audit snapshots.
- Audit dashboard rows are fetched only when the actor also has `support.audit.view`.
- Added migration `20260918020000_support_reporting_audit` for permission defaults only.
- Added permission, audit-privacy and HTML escaping regression coverage.
