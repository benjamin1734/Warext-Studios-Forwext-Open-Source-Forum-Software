# Forwext 0.0.3-dev

Roadmap step 04.05 completes the OAuth/connected-account backend foundation.

- Google and Discord provider implementations.
- Provider abstraction/registry for future providers.
- OAuth state with SHA-256 persistence and one-time consumption.
- PKCE S256 on authorization-code flows.
- Exact HTTPS redirect URI allowlists.
- Verified-provider-email-only automatic linking to an existing local account.
- Duplicate/cross-user link prevention at service and database uniqueness layers.
- Safe unlink rule that preserves at least one authentication method.
- Provider client secrets loaded through the encrypted secret store.
- Provider access tokens remain transient and are not persisted.
- Core migration `20260915123000_oauth_connected_accounts`.
- Native cPanel baseline remains valid; outbound OAuth HTTP uses cURL when available and the PHP HTTPS stream wrapper fallback otherwise.

Next roadmap step: 04.06 profile and profile-media system.
